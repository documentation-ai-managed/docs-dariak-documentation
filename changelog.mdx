## Release History

<Update label="2024-10-15" description="v2.1.0" tags={["feature", "improvement"]}>

## New Features

- Added real-time collaborative editing for team documents
- Introduced advanced search with filters and sorting options
- Implemented automatic backup and version recovery system

## Improvements

- Enhanced user interface with improved navigation and responsiveness
- Optimized performance for large documentation projects
- Updated API endpoints with better error handling and documentation

</Update>

<Update label="2024-09-20" description="v2.0.0" tags={["feature", "breaking"]}>

## New Features

- Launched complete redesign of the documentation platform
- Added support for custom themes and branding options
- Introduced API integration capabilities for third-party tools

## Breaking Changes

- Updated authentication system requiring re-login for all users
- Changed API endpoint structure - migration guide available
- Removed legacy features no longer supported

</Update>
